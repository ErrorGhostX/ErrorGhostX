## 🚀 Избранные проекты

### 📱 **Relab** — Выпускная квалификационная работа (ВКР)
Комплексная информационная система управления заказами с полноценной поддержкой офлайн-режима.
*   **Android-приложение (Kotlin):** 
    *   Архитектура **Offline-First** — локальная БД Room является единственным источником правды для интерфейса.
    *   **SyncManager:** Двусторонняя фоновая синхронизация с разрешением конфликтов.
    *   Паттерн MVVM, ViewBinding, Navigation Component и встроенная интеграция с ИИ (LLM) в качестве умного ассистента.
*   **Django-бэкенд (Python):**
    *   REST API на DRF и WebSocket-соединения на Django Channels для мгновенной синхронизации чатов и статусов в реальном времени.
    *   БД MySQL, фоновые задачи и push-уведомления (FCM).

### 🎮 **Minecraft MCSM** — Собственные игровые модификации
*   Разработка модов на **Java** с использованием современных API (**Fabric**).
*   Создание кастомных игровых механик, оптимизация рендеринга и работы с памятью, интеграция новых предметов, блоков и сущностей.

### 🤖 **MESHREG & LUGALO** — Телеграм-боты для автоматизации
*   Разработка интеллектуальных Telegram-ботов на **Python** (aiogram / pyTelegramBotAPI).
*   Использование конечных автоматов (FSM) для построения сложных пользовательских сценариев.
*   Интеграция с внешними сервисами (Google API, локальные СУБД) для удобного сбора и регистрации данных.
